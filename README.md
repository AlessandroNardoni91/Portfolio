# Portfolio

English | [Italiano](README.it.md)

A collection of the projects I have developed. Each one has a page with a
description, the features, some technical notes and the technologies used. The
source code is in private repositories, available on request, except for Torre
degli Agli which is public.

## Projects

| Project | Description | Main technologies | Status |
| --- | --- | --- | --- |
| [Volontiamo](projects/volontiamo.md) | Volunteer coordination: organisations, events, activities, shifts, sign-ups | Next.js, React, TypeScript, Supabase, Tailwind CSS | Online at [volontiamo.org](https://volontiamo.org), ready for its first organisations |
| [Vociamo](projects/live-interpretation-platform.md) | Live captions and AI translation for guided tours, lectures and conferences, with one channel per language | TypeScript, LiveKit, Google Cloud Speech, Supabase | Online at [vociamo.app](https://vociamo.app), before the first pilot |
| [Palla Lunga e Pedalare](projects/palla-lunga-e-pedalare.md) | Instagram page about Serie A players, with posts prepared by AI, approved by email and published on schedule | Python, Playwright, Instagram Graph API, GitHub Actions | Online on [Instagram](https://www.instagram.com/pallalungaepedalare/), one post a day |
| [Contattiamo](projects/contattiamo.md) | Assistant inside Claude that finds organisations to contact, prepares the messages and keeps the register, never sending anything by itself | Claude skill, Google Sheets, Gmail | In development |
| [Asta Fantacalcio](projects/asta-fantacalcio.md) | Fantasy football draft auction management, with budget and squad tracking | Python, FastAPI, SQLite, Next.js | Complete, 310 automated tests |
| [Torre degli Agli](projects/torre-degli-agli.md) | Guest guide for an apartment, opened from a QR code, in four languages | HTML, CSS and JavaScript with no dependencies, GitHub Pages | Online, [site](https://alessandronardoni91.github.io/torre-degli-agli/) and [source](https://github.com/AlessandroNardoni91/torre-degli-agli) public |
